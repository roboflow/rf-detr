    Inference API Reference¶

    For a narrative guide with runnable examples, see Inference.

    Predict with a live native model, checkpoint, or exported artifact.

    This facade shares prediction behavior across native models and exported runtimes. model.inference() returns an owned, optimized snapshot of a live model. Passing a live model directly to this constructor borrows it instead: predictions follow later changes to that model.

    Examples:

    Skipped when run as a doctest: requires model weights and an image file.

    >>> from rfdetr import RFDETRInference, RFDETRSmall
>>> predictor = RFDETRSmall().inference(compile=False)
>>> detections = predictor.predict("image.jpg")

    Attributes¶

    class_names property ¶

    Return a copy of the source class names.

    runtime_info property ¶

    Return runtime policy and current input constraints without preparing the model.

    input_shape uses canonical NCHW order with None for dynamic axes. default_shape is the default image height and width. batch_size is an exact requirement; max_batch_size is an upper bound. Neither is a batching request. The returned dictionary is independent of the source.

    Functions¶

    __init__(source, *, device='auto', metadata=None, trust_checkpoint=False, runtime_options=None) ¶

    Create a prediction facade from native weights or an exported artifact.

    Each source accepts its own device vocabulary; a value valid for one format can be refused by another:

    Source Accepted device values
    Live RFDETR model auto only; configure the model's own device instead
    Checkpoint path Any device RFDETR.from_checkpoint accepts; auto defers to it
    ONNX auto (CUDA provider when installed, else CPU), cpu, cuda, cuda:N
    TensorRT auto (cuda:0), cuda (the current CUDA device), cuda:N
    OpenVINO auto (AUTO plugin), cpu, gpu, npu, gpu.N, npu.N, any case
    TFLite, LiteRT auto, cpu
    CoreML auto (all compute units), cpu (CPU only)
    Core AI auto, cpu; gpu and ane are refused as mere preferences
    ExecuTorch By delegate: XNNPACK auto/cpu, CoreML auto, QNN auto/qnn

    A live model owns its device policy. Omit device for that source; configure the native model itself to select its device.

    Parameters:

    Name Type Description Default

    source ¶

    		 RFDETR | str | PathLike[str]

    A live RFDETR model or a checkpoint or exported artifact path.

    		 required

    device ¶

    		 str | device

    Runtime device, as a string or torch.device (converted with str()), or "auto" to inherit the source device.

    		 'auto'

    metadata ¶

    		 Mapping[str, Any] | str | PathLike[str] | None

    Missing inference semantics for an older exported artifact, supplied as a JSON file path or JSON-serializable mapping. Accepts a plain metadata object or an artifact_sha256 / metadata envelope whose digest matches the artifact. Required fields describe the format, task, input shape, outputs, normalization, classes and postprocessing; see "Metadata for older exports" in the export basics guide for the complete schema and example. Supplied values must agree with stored metadata; unknown fields and unsupported schema versions are rejected. Invalid for native models or checkpoints.

    		 None

    trust_checkpoint ¶

    		 bool

    Allow loading a checkpoint that contains custom Python objects.

    		 False

    runtime_options ¶

    		 Mapping[str, Any] | None

    Settings for an exported artifact's runtime. Each format reads only its own keys and raises ValueError for any other: TensorRT takes cuda_graph, engine_host_code_allowed and verbose (each a bool); OpenVINO takes cache_dir, inference_precision and config; the other formats take none.

    		 None

    Raises:

    Type Description
    FileNotFoundError

    If the artifact or metadata file is missing.
    ImportError

    If a required format extra or runtime package is not installed.
    RuntimeError

    If the host or requested device cannot run the runtime.
    TypeError

    If runtime_options is not a mapping.
    ValueError

    If metadata, runtime_options or device conflicts with a native source; metadata is missing, stale or conflicting; the format is unsupported; the artifact is backbone-only; or the loader refuses a device or runtime option.

    predict(images, threshold=0.5, shape=None, patch_size=None, include_source_image=True, *, antialias=None) ¶

    Run prediction with the shared native and exported inference pipeline.

    Parameters:

    Name Type Description Default

    images ¶

    		 str | PathLike[str] | Image | ndarray[Any, Any] | Tensor | list[str | PathLike[str] | ndarray[Any, Any] | Image | Tensor] | tuple[str | PathLike[str] | ndarray[Any, Any] | Image | Tensor, ...]

    A file path, URL string, PIL image, HWC NumPy array, CHW tensor, or list or tuple of those inputs. HTTP(S) URL strings are downloaded with requests using a 30-second connect and read timeout, which does not bound the total download time. Redirects are followed, and the whole response body is read into memory with no size limit or host restriction. Pass only URLs you trust; for untrusted URLs, download and validate the image yourself and pass the decoded image instead.

    		 required

    threshold ¶

    		 float

    Minimum confidence score for a prediction.

    		 0.5

    shape ¶

    		 tuple[int, int] | None

    Optional input height and width.

    		 None

    patch_size ¶

    		 int | None

    Advanced override for shape divisibility validation; it does not change the backbone.

    		 None

    include_source_image ¶

    		 bool

    Include each source image in prediction metadata.

    		 True

    antialias ¶

    		 bool | None

    Use antialiasing during image resize. None uses the artifact metadata's resize_antialias for exported sources and False for native sources. An explicit boolean overrides the default; match the checkpoint training resize.

    		 None

    Returns:

    Type Description
    Detections | KeyPoints | list[Detections | KeyPoints]

    A Supervision prediction object or a list of prediction objects.

    Raises:

    Type Description
    TypeError

    If an unknown prediction keyword is supplied.
    ValueError

    If shape or patch_size is invalid, or the source cannot accept the channel count, batch size or input shape.

    Examples:

    Skipped when run as a doctest: requires model weights and image files.

    >>> from rfdetr import RFDETRInference, RFDETRSmall
>>> predictor = RFDETRSmall().inference(compile=False)
>>> results = predictor.predict(["a.jpg", "b.jpg"], threshold=0.4)
>>> len(results)
2
